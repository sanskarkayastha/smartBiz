## Summary

API Gateway was completely non-functional (returned 401 on all requests).
Root cause: No SecurityConfig, Spring Security default blocked all routes before JWT filter.

Fixed 9 critical items across backend, mobile, and infrastructure:

### Critical Fixes (Gateway Restore)
- Add GatewaySecurityConfig: permits all, lets JWT GlobalFilter handle auth
- Exclude spring-boot-starter-web from api-gateway (Servlet/WebFlux conflict)
- Add SessionCreationPolicy.STATELESS to auth-service
- Fix CRM updatePurchaseTotal endpoint: add X-User-Id header + user ownership validation

### Features
